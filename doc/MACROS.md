# Macros

[← Back to the README](index.md)

Lancer Automations ships a compendium of ready-made macros, the **`L.A -`** set. Drag one to the hotbar and run it on the selected token. Each runs the matching feature documented in the other guides.

---

## Actions & Tools

| Action | What it does | Tool | What it does |
|--------|--------------|------|--------------|
| Skirmish | Attack with a single weapon. | Knockback | Push or pull tokens a set distance. |
| Barrage | Attack with up to two weapons. | Throw Weapon | Throw a weapon onto the field as a token. |
| Ram | Melee ram that knocks the target Prone. | Pickup Weapon | Pick a thrown weapon back up. |
| Grapple | Grapple, Break Free, or End Grapple. | Deploy Item | Place one of the actor's deployables. |
| Brace | Brace, as a reaction. | Reinforcement | Set up units to arrive later in combat. |
| Overwatch | Trigger an Overwatch skirmish. | Reactor Meltdown | Start a reactor-meltdown countdown. |
| Lock On | Lock On a target. | Reactor Explosion | Detonate the meltdown now. |
| Disengage | Disengage for the turn. | Suicide | Drop the token to 0 structure, stress, and HP. |
| Bolster | Grant Bolster to an ally. | Rest | Open the rest / repair dialog. |
| Aid | Aid an adjacent ally. | Downtime | Run a downtime activity. |
| Fragment Signal | Apply Impaired (or Slow + Impaired) on a tech hit. | Add Reserve | Add a pilot reserve or bonus. |
| Invade | Run a tech Invade. | Reload One Weapon | Reload a single weapon. |
| Search | Search for hidden characters. | End Active Item | End an active (toggled) item. |
| Scan | Scan a target. | Choice Menu | Build and send a choice or vote card. |
| Hide | Become Hidden. |  |  |
| Shut Down | Shut down. |  |  |
| Boot Up | Boot up from Shut Down. |  |  |
| Eject | Eject the pilot from the mech. |  |  |
| Dismount | Dismount the pilot from the mech. |  |  |
| Handle | Drag or lift an adjacent object or character. |  |  |
| Interact | Manipulate a nearby object. |  |  |
| Squeeze | Count as one Size smaller, and Prone. |  |  |
